O que necessito para viajar?

Para viajar a marte vai ser necessario

  • Exames medicos gerais
  • Duas semanas de treino especializado
  • Passaporte interestellar valido
  • Assinar um termo de responsabilidade

Procedimentos antes da viajem:

  1. Escolher a data de viagem
  2. Efetuar os exames medicos necessarios
  3. Participar duas semanas de treino especializado com exito
  4. Assinar o termo de responsabilidade

A viagem so esta disponivel para maiores de idade
